# Glob Web

Vite + React + TypeScript. Runs on port **5174**.

## Setup
```
npm install
cp .env.example .env   # VITE_API_URL, VITE_GOOGLE_MAPS_API_KEY, VITE_MAP_HOME
npm run dev
```
Needs the Glob API running (default http://localhost:3008). Maps need a Google key with Maps JavaScript + Places enabled.
